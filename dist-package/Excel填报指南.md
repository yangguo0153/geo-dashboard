# Excel 数据填报指南（给同事）

**看板地址（部署在 Fly.io）：**

```
管理员入口（能上传数据）：
https://geo-dashboard.fly.dev/?token=geo-admin-2026

只读入口（只能看数据）：
https://geo-dashboard.fly.dev/?token=geo-view-2026
```

> 首次打开带 token 的链接后，浏览器会记住登录状态，下次直接打开域名即可。
> **不需要安装任何软件**，打开浏览器就能用。

**看板需要你定期上传 Excel 文件来更新数据。** 文件里有三个工作表（Sheet），分别对应三种关键词监测。

---

## 快速上手

1. 打开文件夹里的 **`GEO监测数据模板.xlsx`**
2. 按下面的说明填数据
3. 打开看板，右上角点「上传数据」，选择填好的文件
4. 上传成功后看板会自动更新

> 系统会根据你的检测日期自动识别月份。比如日期是 `2026-04-15`，数据就归到 2026 年 4 月。
> **注意：重新上传同一月份的文件会覆盖该月已有数据。**

## 工作表 1：推荐词

这个表有两个区域，**上半部分是监测记录，下半部分是关联度评测**，不要混在一起。

### 上半部分：监测记录（列头在第 1 行）

| 列 | 填什么 | 示例 | 说明 |
|----|--------|------|------|
| A: 词根 | 关键词的根词 | `智己汽车` | 同一根词可以有多条具体问句 |
| B: 具体问句 | 在 AI 里搜索的完整句子 | `智己汽车怎么样` | 越接近真实用户提问越好 |
| C: 平台 | 哪个 AI 平台 | `豆包` | 可选：豆包 / 千问 / DeepSeek / 元宝 |
| D: 检测日期 | 哪天检测的 | `2026-04-01` | 格式 YYYY-MM-DD |
| E: 是否露出 | AI 回答里是否出现了智己 | `是` 或 `否` | 填"是"或"否" |
| F: 截图编码 | 截图文件名/编号 | `SS001` | 没有截图留空 |
| G: 备注 | 补充说明 | `未露出` | 可选 |

**示例数据（已有）：**
```
智己汽车 | 智己汽车怎么样 | 豆包 | 2026-04-01 | 是 | SS001 |
智己汽车 | 智己汽车价格 | 千问 | 2026-04-01 | 否 |  | 未露出
```

### 下半部分：关联度评测（从"关联度评测"那一行开始）

| 列 | 填什么 | 示例 |
|----|--------|------|
| A: 词根 | 与上面一致的根词 | `智己汽车` |
| B: 平台 | 与上面一致的平台 | `豆包` |
| C: 产品适配度 | 1~5 分打分 | `4` |
| D: AI自然呈现率 | 0~100 的百分比 | `25` |
| E: 关联度 | **公式自动算，不要手动填** | 系统自动计算 |
| F: 词包级别 | **公式自动算，不要手动填** | 系统自动计算 |

> **C (产品适配度)**：这个词与智己汽车的产品关联有多紧密？1=完全不相关，5=直接相关
> **D (自然呈现率)**：在所有搜索中，AI 自然提到这个词的比例是多少？填数字即可（比如 25 = 25%）
> **E 和 F 列有 Excel 公式**，会自动算，**不要填数字进去**，否则公式会被覆盖。如果要新增行，直接复制上面一行的公式拖下来。

## 工作表 2：对比词

| 列 | 填什么 | 示例 | 说明 |
|----|--------|------|------|
| A: 词根 | 关键词根词 | `智己汽车` | |
| B: 具体问句 | 完整问题 | `智己汽车对比小鹏` | 通常包含竞品对比 |
| C: 平台 | 哪个 AI 平台 | `豆包` | 同上，4 个平台之一 |
| D: 检测日期 | YYYY-MM-DD | `2026-04-01` | |
| E: 偏向智己 | AI 回答是否推荐智己 | `是` 或 `否` | 填"是"或"否" |
| F: 词包级别 | 词包的难度等级 | `一级` | 可选：一级 / 二级 / 三级 |
| G: 截图编码 | 截图编号 | `CP001` | 可选 |
| H: 备注 | 补充 | `竞品优势` | 可选 |

**词包级别说明：**
- **一级** = 最难（关联度 ≤30%），如泛行业词
- **二级** = 中等（关联度 30%-50%），如产品对比词
- **三级** = 较易（关联度 50%-60%），如品牌专属词

## 常见错误

| 错误现象 | 原因 | 解决办法 |
|----------|------|----------|
| 上传后提示"Token required" | 未登录 | 从上面的管理员链接重新打开即可 |
| 上传后提示"Admin access required" | 用了只读 Token | 用上面的管理员入口链接打开 |
| 上传成功但数据不对 | 表格列填错位置 | 对照上面的列说明检查 |
| 关联度数据全为 0 | E/F 列的公式被覆盖了 | 删掉填的数字，重新从示例行复制公式 |
| 检测日期填了但月份不对 | 日期格式不对 | 必须用 YYYY-MM-DD 格式，如 `2026-04-01` |
| 平台名称不识别 | 填了系统不认识的平台名 | 用这 4 个之一：豆包 / 千问 / DeepSeek / 元宝（通义千问会被自动识别） |

## 简单的工作流程建议

```
每月初：
  1. 打开上个月的模板，把日期改成当月
  2. 清空旧数据（保留列标题行和公式行）
  3. 按监测结果填入新的检测记录
  4. 上传到看板

每周/每两周：
  1. 打开当前月的文件
  2. 在最后追加新的监测记录
  3. 重新上传（会覆盖该月旧数据）
```

> 提示：可以用 **`GEO测试数据.xlsx`** 做练习，先上传这个文件看看效果，熟悉了再填真实数据。
