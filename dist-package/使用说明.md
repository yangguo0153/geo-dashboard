# 智己 GEO 监测看板

GEO（Generative Engine Optimization）效果监测工具。监测豆包、千问、DeepSeek、元宝四个 AI 搜索平台上智己汽车的关键词表现。

---

## 快速开始（推荐方式 — 无需安装）

看板已部署到云端，打开浏览器即可使用：

```
管理员入口（能上传数据）：
https://geo-dashboard.fly.dev/?token=geo-admin-2026

只读入口（只能看数据）：
https://geo-dashboard.fly.dev/?token=geo-view-2026
```

> 首次打开后浏览器会记住登录状态，后续直接打开域名即可。

## 本地运行（备用方案）

以下说明适用于离线环境或本机测试。

### 第一步：安装 Node.js

> 这是让程序运行的基础环境，只需要装一次。

**Windows 电脑：**
1. 打开浏览器，访问 https://nodejs.org/
2. 下载左侧绿色的 **LTS** 版本（推荐给多数用户）
3. 双击下载的文件，一路点「下一步」安装完成
4. 安装完成后**重启电脑**

**Mac 电脑：**
1. 打开浏览器，访问 https://nodejs.org/
2. 下载左侧绿色的 **LTS** 版本（推荐给多数用户）
3. 双击下载的 .pkg 文件，一路点「继续」安装完成
4. 安装完成后重启电脑

> 安装过程很简单，完全不需要懂编程。如果公司限制了下载网站，联系 IT 部门帮忙安装即可。

---

### 第二步：启动看板

**Windows 电脑：**
1. 把整个文件夹复制到电脑上（建议放桌面）
2. 双击 **`启动看板.bat`**
3. 首次启动会自动安装依赖，等待 1-2 分钟
4. 浏览器会自动打开看板页面

**Mac 电脑：**
1. 把整个文件夹复制到电脑上（建议放桌面）
2. 双击 **`启动看板.command`**
3. 首次启动会自动安装依赖，等待 1-2 分钟
4. 终端会打开，浏览器会自动弹出看板页面

> 如浏览器未自动打开，手动访问：**http://localhost:3001**

### 高级操作（可选）

以下操作不用每次做，配一次即可。

**设置开机自启：**
如果想让看板开机后自动启动（省去手动双击步骤）：

- **Windows**：把 `启动看板.bat` 拖到「开始菜单 > 启动」文件夹里
- **Mac**：系统设置 > 通用 > 登录项 > 添加 `启动看板.command`

**更换 Token：**
打开文件夹里的 `.env` 文件（用记事本/文本编辑），修改以下两行：
```
ADMIN_TOKEN=你自己定的密码
VIEW_TOKEN=你自己定的密码
```
改完后保存，重启看板即可生效。

**查看 Token：**
如果忘记当前 Token，打开 `.env` 文件就能看到。

---

### 如果遇到问题

| 问题 | 解决办法 |
|------|----------|
| 双击 bat 没反应 | 确认 Node.js 已安装（搜"命令提示符"输入 `node -v`，看到版本号即可） |
| 提示端口被占用 | 打开 `.env`，把 `PORT=3001` 改成 `PORT=3002` 再试 |
| 页面白屏/打不开 | 确认黑色窗口/终端在运行中，没有报错 |
| 上传 Excel 报错 | 确认模板格式正确，列名与系统要求一致 |
| 其他问题 | 联系技术同事 |
